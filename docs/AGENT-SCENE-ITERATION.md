## Reusable iteration loop

1. Bind the user's current tab. Do not reload unsaved work. Read `scene.info()` and find the target by name.
2. Inspect exact nodes and component schemas. Resolve local versus world coordinates and collision ownership before changing geometry.
3. Make one object correction or one coherent named subtree. Inspect returned revision and created IDs.
4. Capture a useful view, display the image, and inspect it. Use overview and close-up views. Review in Play to exclude edit-only helpers.
5. Run scene-specific behavior checks. Schema validation is insufficient for headroom, solid walls, takeoff overlap, and landing reach.
6. Correct failed geometry through the same window API. Repeat the same tests; keep the shared undo history.
7. Return to Edit. If `saveMethod` is `save`, call it. Otherwise export the whole document to the source file through an explicit file handoff.
8. Verify revision stability and saved content equality. Leave the editor in a useful review view.

CDP adapter used in the browser REPL:

```js
const cdp = await tab.capabilities.get('cdp');
async function run(expression) {
  const result = await cdp.send('Runtime.evaluate', {
    expression, returnByValue: true, awaitPromise: true,
  });
  if (result.exceptionDetails) throw Error(JSON.stringify(result.exceptionDetails));
  return result.result.value;
}
```

Local save handoff (start from the repository root):

```sh
node scripts/receive-editor-scene.mjs docs/public/prefabs/jumper-course.json http://localhost:3001
```

Use the exact endpoint printed by that process; it is unique to this receiver. In the editor page's runtime:

```js
const revision = scene.info().revision;
const response = await fetch(endpoint, {
  method: 'POST', headers: { 'Content-Type': 'application/json' },
  body: scene.exportJSON(),
});
const receipt = await response.json();
if (!response.ok) throw Error(JSON.stringify(receipt));
if (revision !== scene.info().revision) throw Error('Scene changed while saving; save again.');
```

The receiver exits after success and stops accepting new connections after ten minutes. It cannot choose an arbitrary destination from an HTTP request. Backups are named `destination.<timestamp>.before-agent-save`; retain them outside the public assets directory after review. This is an export transport, not a new `scene.save` API. No core editor API modifications were necessary.

## URL and embedded prefab parity audit

Fixed three behavior bugs:

- A PrefabRef initialized from a cached definition skipped loading and never retained the document. Enough idle loads could evict that definition and a later render could lose the prefab. Every mounted reference now holds `AssetRuntime.acquirePrefab()` until URL change/unmount, preserving the instance store across unrelated rerenders.
- Unpack bypassed the rendered cache with a fresh fetch. A changed server response could therefore unpack a different asset than the user saw. `AssetRuntime.readPrefab()` reads an isolated copy through the same retained document cache used by rendering/preparation; the editor host delegates to it.
- Sparse prefabs with an omitted default material, or an unresolved material ID, could inherit an unrelated outer-scene material after unpacking. Material scoping now explicitly includes the prefab's normalized default and remaps unresolved references to that local fallback.
